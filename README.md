> ### 🧠 A Note on How This Was Built
>
> This entire project was **written by hand** — no AI code generators, no Copilot, no ChatGPT, no automated scaffolding. Every line of HTML, CSS, and JavaScript was crafted manually. The tools, the UI, the router, the theme engine — all built from scratch with pure vanilla JavaScript.
>
> *Why does this matter?* Because when you build something yourself, you understand every corner of it. There's no black box. You can open any file, read any function, and know exactly what it does. That's the philosophy behind this project — **transparency, simplicity, and ownership.**

## ✨ What's Inside

- **64 tools** across 10 categories — from GPA calculators to JWT decoders
- **100% offline** — works without internet after first load
- **No sign-up, no tracking, no ads** — just open and use
- **Dark/Light theme** with smooth transitions
- **Data persistence** — all data saved in your browser's localStorage
- **Export/Import** — backup and restore everything as JSON
- **Responsive design** — works on desktop, tablet, and mobile
- **Keyboard shortcuts** — `Ctrl+B` toggle sidebar, `Ctrl+/` search, `Esc` close modals
- **Zero dependencies** — pure HTML/CSS/JS, no React, no Vue, no jQuery, no Bootstrap
- **~274KB total** — smaller than most single-page app bundles

## 📁 Project Structure

```
student-study-hub/
├── index.html              # Single entry point — loads everything
├── css/
│   └── style.css           # All styles — dark/light theme, animations, responsive
├── js/
│   ├── router.js           # Hash-based SPA router (#tool-name)
│   ├── theme.js            # Dark/light theme with system preference detection
│   ├── storage.js          # localStorage wrapper, Toast, Modal, utilities
│   ├── nav.js              # Sidebar navigation — auto-generated from config
│   ├── home.js             # Dashboard with stats, deadlines, quick access
│   ├── app.js              # App init — sidebar toggle, keyboard shortcuts
│   └── tools/              # 64 independent tool modules
│       ├── gpa.js          # Each tool is self-contained
│       ├── pomodoro.js     # Registers its own route
│       ├── flashcards.js   # Manages its own data
│       └── ... (61 more)
└── README.md
```

### Architecture
- **No build step** — open `index.html` and it works
- **No frameworks** — vanilla JavaScript only
- **No npm, no webpack, no bundler** — just files
- **Each tool is independent** — add/remove tools without breaking others
- **Hash routing** — `#gpa`, `#pomodoro`, `#flashcards` — bookmarkable, shareable
- **localStorage** — all data persists in the browser

## 🎨 Design Philosophy

This project follows three principles:

1. **Zero Dependencies** — No React, no Vue, no jQuery, no Bootstrap. Every byte of code is hand-written and understood.

2. **Offline First** — No API calls, no CDN fetches, no external resources. Once loaded, it works forever — on a plane, in a basement, anywhere.

3. **Student Built, Student First** — Built by a 15-year-old student who needed these tools. Every feature exists because it solves a real problem.
